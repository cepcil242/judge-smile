Entry for the make.fun competition **Make the Judge Smile**
(`u-gentle-badger-68-make-the-judge-smile-9228676d`).

`main.ts` (Node 22, standard library only, no network) writes a single line
— at most 200 characters — about a small good thing that happened today to
`/output/entry.txt` (or `$ENTRY_OUTPUT_PATH` when set). The line is validated
before writing: 1–200 Unicode characters, not only whitespace.

> This morning the bus driver waited while an old man shuffled across the
> road, then waved him aboard like a long-lost friend — and the whole bus
> broke into applause.

Run it with:

```sh
node main.ts
```
